# X CORP SHOP — Telegram Bot

Магазин на aiogram 3: каталог, корзина, заказы, промокоды, рефералка,
оплата (CryptoBot / xRocket / TON / карта / баланс), админ-панель,
логи событий в Telegram-группу.

## Структура

```
main.py            — точка входа (python main.py)
.env               — конфигурация (токены, админ, лог-группа, пути)
.env.example       — пример конфига
requirements.txt   — зависимости
check.py           — самопроверка без запуска бота (python check.py)
e2e_test.py        — e2e-тест всех сценариев с мок-Telegram (python e2e_test.py)
live_test.py       — живая проверка с реальным токеном (python live_test.py)
app/
  config.py        — чтение .env
  compat.py        — автоустановка зависимостей при первом запуске
  db.py            — SQLite: схема и все запросы
  utils.py         — клавиатурные стили, безопасные отправки, курсы валют
  texts.py         — тексты и премиум-эмодзи
  keyboards.py     — инлайн-клавиатуры
  payments.py      — CryptoBot / xRocket API
  logs.py          — логи в Telegram-группу + ежесуточная статистика
  variables.py     — «Переменные» в админке (настройки без перезапуска)
  handlers/
    start.py       — /start, меню, правила, поддержка
    catalog.py     — каталог, карточка товара, корзина
    profile.py     — профиль, мои заказы, рефералка, отзывы
    promo.py       — промокоды
    topup.py       — пополнение баланса
    payment.py     — оплата (CryptoBot, xRocket, TON, карта, баланс), отмена
    admin.py       — админ-панель
```

## Запуск

1. Заполни `.env` — минимум `BOT_TOKEN` (от @BotFather).
2. `python main.py` — недостающие библиотеки установятся сами.
3. Проверка без запуска бота: `python check.py`.

## Переменные в админке

Кнопка **«Переменные»** в админ-панели: просмотр и изменение настроек
прямо из Telegram, без правки `.env` и перезапуска. Значения хранятся
в БД и применяются мгновенно; отправь `-` при изменении — вернётся
значение из `.env`.

Можно менять: TON-адрес, номер карты, юзернейм поддержки, канал (ссылка
и ID для проверки подписки), реферальный процент, надбавку CryptoBot,
ID лог-группы и топика, час суточной статистики, API xRocket.

**Не** входит и не показывается: `BOT_TOKEN`, токены CryptoBot/xRocket
(только статус «задан/не задан») и список админов — они меняются только
в `.env`.

## База данных

Файл базы: `<DATA_DIR>/shop.db`, по умолчанию **`/app/data`** — эта папка
переживает перезапуск сервера/контейнера. Если рядом со старым `main.py`
лежал `shop.db`, при первом запуске он автоматически копируется в новую
папку (ничего не теряется).

Устойчивость к нагрузке: WAL-режим, `synchronous=NORMAL`, ожидание
блокировки до 15 сек на всех соединениях — параллельные запросы не
роняют базу с «database is locked».

Для локального теста на Windows можно указать в `.env`:

```
DATA_DIR=data
```

## Логи в Telegram-группе

Бот шлёт события в группу из `LOG_CHAT_ID`, по темам с эмодзи-заголовками:

| Тема | Что попадает |
|---|---|
| 👤 Пользователи | новый пользователь, вход в бота (по /start), рефералы |
| 📦 Товары | добавление, вкл/выкл, удаление, наличие, «товар заканчивается» (≤3 шт) |
| 🛒 Заказы | **только покупки**: оплаты всеми способами, выдача, отклонение скрина |
| 🧾 Оформления | заказы/корзины созданы (НЕ оплачены), отмены до оплаты (ручные и авто через 3 ч) |
| 💰 Оплата | запросы пополнения, счета, скрины на проверку, подтверждения пополнений |
| 📦 Товары | добавление, вкл/выкл, удаление, изменение наличия |
| 🎟 Промокоды | создание и активации |
| 📢 Рассылка | результат рассылки |
| 🎫 Поддержка | новые обращения, ответы |
| ⭐ Отзывы | новые отзывы |
| 🛠 Админ-действия | ban/unban, setbal, write, баннер |
| 📊 Статистика | ежесуточная сводка (час — `LOG_DAILY_HOUR` по времени сервера) |
| 🚀 Система | запуск бота |
| ⚠️ Ошибки | необработанные исключения (с троттлингом) |
| 🗄 Бэкапы БД | файл базы 2 раза в сутки |

**Темы (форум):** если в группе включены темы — бот **сам создаёт тему
на каждую категорию** и раскладывает события по ним. Если бот не создаёт
темы, выдай ему право «Управление темами». Чтобы принудительно слать всё
в один топик — укажи `LOG_TOPIC_ID`. Если чат не форум — события идут
обычными сообщениями.

- Если бот не может писать в группу (не добавлен/не админ), в консоли
  будет предупреждение, а логи временно приостановятся — бот при этом
  продолжает работать.
- Чтобы выключить логи, оставь `LOG_CHAT_ID` пустым.
- Если группа когда-нибудь будет преобразована в супергруппу, бот сам
  переключится на новый id без правок.

## Бэкапы базы данных

2 раза в сутки (часы — `BACKUP_HOURS`, по умолчанию `6,18` по времени
сервера) бот делает консистентную копию `shop.db` через SQLite backup API:

1. Кладёт её в `DATA_DIR/backups/` (хранятся последние `BACKUP_KEEP`, по
   умолчанию 7 — старые удаляются автоматически).
2. Отправляет файл в лог-группу, в тему **«🗄 Бэкапы БД»**.

Восстановление: остановить бота, заменить `DATA_DIR/shop.db` файлом
бэкапа, запустить бота.

## Основные переменные .env

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | токен бота (обязательно) |
| `ADMIN_IDS` | `152706581,7145919720` | ID админов через запятую (админ-панель + ЛС-уведомления) |
| `LOG_CHAT_ID` | — | группа для логов |
| `LOG_TOPIC_ID` | — | топик в группе (если форум) |
| `LOG_DAILY_HOUR` | `12` | час суточной статистики |
| `DATA_DIR` | `/app/data` | папка для базы данных |
| `CRYPTO_BOT_TOKEN` | — | токен Crypto Pay |
| `XROCKET_TOKEN` | — | токен xRocket Pay |
| `AUTO_CANCEL_HOURS` | `3` | автоотмена неоплаченных заказов |

Реквизиты и параметры магазина (TON-адрес, карта, поддержка, канал,
реферальный %, надбавка CryptoBot) в `.env` **не хранятся** — их дефолты
в коде, а менять нужно в админ-панели: **«Переменные»** (применяется
сразу, без перезапуска).
